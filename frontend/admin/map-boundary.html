    Map Boundary

    Barangay Outline

    • Click the map to add a point. Once there are 3 points, a new point is placed on the nearest edge, so clicking beside an edge refines it.
    • Drag a point to move it. Right-click a point to remove it.
    • Upload File accepts GeoJSON (.geojson/.json) or KML (.kml, e.g. exported from Google My Maps or Google Earth). If the file holds several shapes, the largest one is used.
    • The yellow dots are the streets citizens can pick when filing a report. + Add Street, then click the map to place a new one — the outline should take them in.
